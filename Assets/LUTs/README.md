# LUT sources

The tone mapping LUTs (look-up textures) in this folder are HDR .exr files representing 3D textures with Alexa LogC El 1000 encoded coordinates.

The LUTs come from these sources:

**AgX folder**: These LUTs come from the GitHub repository [meenphie/AgX-Tonemapping-Unity](https://github.com/meenphie/AgX-Tonemapping-Unity).

**GT7 folder**: These LUTs are exported from the GT7 shader and materials in the [Baking](../Baking/Tonemappers/) folder. The shader is derived from the implementation in the GitHub repository [aletschfirn/gt7tonemapper](https://github.com/aletschfirn/gt7tonemapper), which itself is derived from the [official sample code](https://blog.selfshadow.com/publications/s2025-shading-course/pdi/supplemental/gt7_tone_mapping.cpp). There are associated [slides here](https://blog.selfshadow.com/publications/s2025-shading-course/pdi/s2025_pbs_pdi_slides_v1.1.pdf).

**Hue Preserving folder**: These LUTs are exported from an old tone mapper implementation of mine. They are not very good, but are included for comparison purposes.

**Identity**: This LUT (where the output is the same as the input) is generated by the LUT Exporter tool in this repository.

**PBR Neutral**: This LUT are exported from the PBR Neutral shader in the [Baking](../Baking/Tonemappers/) folder. The shader is derived from the implementation in the GitHub repository [KhronosGroup/ToneMapping](https://github.com/KhronosGroup/ToneMapping). There's an associated [article here](https://modelviewer.dev/examples/tone-mapping).

**Reinhard folder**: These LUTs are exported from the Reinhard shaders and materials in the [Baking](../Baking/Tonemappers/) folder. The shaders are derived from the implementations in the blog post [64.github.io/tonemapping/](https://64.github.io/tonemapping/).

**Tony McMapface**: This LUT comes from the GitHub repository [meenphie/Tony-McMapface-Tonemapping-Unity](https://github.com/meenphie/Tony-McMapface-Tonemapping-Unity) which is derived from the original provided LUT (in a different format) in the GitHub repository [h3r2tic/tony-mc-mapface](https://github.com/h3r2tic/tony-mc-mapface).

**Tony Vibrant folder**: These LUTs are exported from the Tony Vibrant custom tone mapper implementation in the included modified version of Unity's Post-Processing Stack v2. Most of the shader implementation is in the file [TonyVibrant.hlsl](../../Packages/com.unity.postprocessing@3.5.4/PostProcessing/Shaders/TonyVibrant.hlsl), though it depends on tone mapping curve functions that are part of PPSv2, used for its 'Custom' tone mapping mode.

**Uncharted 2**: This LUT is exported from the Uncharted 2 shader and material in the [Baking](../Baking/Tonemappers/) folder. The shader is derived from the implementations in the blog post [64.github.io/tonemapping/](https://64.github.io/tonemapping/).
